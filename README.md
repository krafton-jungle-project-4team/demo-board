# 나만의 무기 만들기

프레임워크를 사용해 바로 개발 가능한 보일러플레이트 예시를 만들기 위한 개인 프로젝트다.

간단한 게시판을 구현하되, 게시판 기능 자체보다 실전 개발을 시작할 수 있는 구조와 기능을 탐색하고 완성하는 데 목적이 있다.

## 목표

- 프레임워크 기반 프로젝트 구조 정리
- 게시판 예시를 통한 기본 CRUD 흐름 구현
- 인증, 라우팅, 데이터 접근, 검증, 테스트 등 보일러플레이트에 필요한 요소 탐색
- 새 기능을 바로 얹을 수 있는 개발 기반 마련

## 비목표

- 복잡한 게시판 도메인 구현
- 대규모 서비스 수준의 기능 완성
- 특정 기능의 과도한 최적화
