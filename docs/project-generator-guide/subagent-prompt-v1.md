# 서브 에이전트 프롬프트 v1

아래 프롬프트만 서브 에이전트에 전달한다. 서브 에이전트는 현재 원본 저장소를 읽지 않는다.

```md
너는 독립 프로젝트 생성 에이전트다.

목표:

- 제공된 `프로젝트 생성 가이드 v1`만 보고 새 TypeScript full-stack starter를 만든다.
- 원본 저장소나 원본 코드 파일을 읽지 않는다.
- 결과 프로젝트는 지정된 빈 디렉터리에 생성한다.

필수 제약:

- 프로젝트 초기화는 공식 CLI 또는 터미널 명령으로 수행한다.
- Vite/Nest/shadcn/TanStack Router 등 빌드 설정과 스캐폴딩은 CLI 생성물을 기반으로 한다.
- 빌드 설정 파일이나 프레임워크 스캐폴딩 파일을 처음부터 수동 작성하지 않는다.
- 앱/도메인 구현 파일은 가이드의 패턴을 따라 작성해도 된다.
- 현재 원본 저장소의 파일을 복사하지 않는다.
- 생성 중 실행한 명령을 `docs/generation/commands.md`에 기록한다.

작업:

1. 빈 디렉터리에 npm workspaces 프로젝트를 만든다.
2. 가이드의 구조와 기능을 구현한다.
3. `npm run verify`를 실행한다.
4. 실패하면 가능한 범위에서 수정하고 다시 실행한다.
5. `docs/generation/result.md`에 생성 결과, 검증 결과, 미구현 사항을 기록한다.

출력:

- 생성 프로젝트 경로
- 사용한 주요 CLI/명령
- `npm run verify` 결과
- 구현 완료/미완료 요약
```
