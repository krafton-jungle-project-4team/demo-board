# 프로젝트 생성 가이드

날짜: 2026-06-12

## 이유

현재 코드베이스를 직접 복사하지 않고도 가이드 문서만으로 기능, 구조, 구현 패턴이 재현되는지 검증하기 위해서다.

## 작업

- 이 메모가 포함된 커밋에서 `docs/project-generator-guide`를 추가했다.
- 현재 기준선, 평가 기준, v1 생성 가이드, 서브 에이전트 프롬프트, 반복 기록 파일을 작성했다.
- 가이드에는 세션 기반 사용자 처리, SQL-first DB, shared contract, API envelope, UI primitive, Codex skill 기반 FE 개선 루프를 포함했다.
- v1 생성 2회는 `npm run verify`를 통과했지만 API CRUD가 in-memory store로 구현되어 90% 기준에 미달했다.
- v2는 DB-backed 구현 금지/필수 조건을 보강했고, 생성 2회가 보조 정적 점수 97% 이상과 `npm run verify` 재실행 통과를 만족했다.
- v3 압축판은 v2 513줄을 247줄로 줄였고, 생성 결과가 보조 정적 점수 130/135와 `npm run verify` 재실행 통과를 만족했다.
- v4 최소판은 v2 513줄을 223줄로 줄였고, 생성 결과가 보조 정적 점수 129/135와 `npm run verify` 재실행 통과를 만족했다.
- 이후 목표 확장에 따라 2단계 작업 프롬프트 하네스, 폴더별 `AGENTS.md`, 스킬 사용 로그, 단순 `bookmarks` 기능 프롬프트 검증 기준을 추가했다.
- v5는 생성 에이전트가 starter만 만들고, 별도 기능 에이전트가 단순 `bookmarks` 프롬프트만 받아 기능을 추가하는 방식으로 검증했다.
- v5 생성 직후 점수는 151/157, 기능 추가 후 하네스 점수는 192/198이고, 본 작업자가 기능 추가 후 `npm run verify`를 재실행해 통과를 확인했다.

## 결과

- v2 상세 가이드가 90% 기준을 충족했다.
- v4 최소 가이드가 압축 후 80% 기준을 충족했다.
- v5 하네스가 생성 후 단순 기능 프롬프트 품질 검증을 충족했다.
- 남은 보강점은 Docker API smoke와 `.env.example` 위치 같은 세부 기준 강화다.
