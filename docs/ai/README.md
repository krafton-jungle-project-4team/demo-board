# AI 작업 기록

AI가 수행한 구체적이고 의미 있는 작업 기록을 보관한다.

원칙:

- 채팅 없이 이해될 만큼 충분하되 최대한 간결하게 쓴다.
- 큰 작업과 메모는 같은 작업 단위로 묶고, 가능하면 같은 커밋에 포함한다.
- 이유, 작업(관련 커밋), 결과(검증/후속 작업)를 포함한다.
- 현재 메모가 포함된 커밋은 `이 메모가 포함된 커밋`으로 적는다.
- 파일명은 `001_short-task-name.md`처럼 순번으로 시작한다.
- 날짜는 파일명 대신 문서 내부에 적는다.

파일명 형식:

```text
001_short-task-name.md
```
