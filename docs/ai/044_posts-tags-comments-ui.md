# 게시글 태그 댓글 UI

날짜: 2026-06-10

## 이유

게시글 API에는 태그와 댓글 기능이 있지만 Web 화면에서 선택, 필터, 댓글 작성/수정/삭제를 할 수 없었다.

## 작업

- 이 메모가 포함된 커밋에서 게시글 목록 태그 필터와 태그 뱃지 표시를 추가했다.
- 게시글 작성/수정 폼에서 태그 선택을 지원하게 했다.
- 게시글 상세에 댓글 목록, 작성, 수정, 삭제 UI를 연결했다.

## 결과

- `GET /api/post-tags`, `GET /api/posts/:id/comments`, `GET /api/posts?tagId=5` 응답을 확인했다.
- `npm run verify` 통과.
